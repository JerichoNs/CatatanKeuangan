Kebijakan Privasi - Catatan Keuangan

Terakhir diperbarui: [ISI TANGGAL]

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Catatan Keuangan ("Aplikasi") mengumpulkan, menggunakan, dan melindungi data pengguna.

1. Data yang Dikumpulkan

  • Data akun: nama dan alamat email, saat mendaftar
  • Data transaksi keuangan: nominal, kategori, tanggal, dan catatan yang kamu masukkan sendiri ke dalam Aplikasi
  • Kami tidak mengakses data finansial dari luar Aplikasi (rekening bank, kartu kredit, dsb) - semua data transaksi adalah data yang kamu ketik manual

2. Cara Data Digunakan

Data yang dikumpulkan digunakan semata-mata untuk menyediakan fitur pencatatan dan pelaporan keuangan pribadi, autentikasi akun, dan menampilkan ringkasan/laporan keuangan kepada pengguna yang bersangkutan.

3. Penyimpanan Data

Data disimpan menggunakan layanan Firebase (Google Cloud Platform) - Firebase Authentication untuk data akun, Firebase Firestore untuk data transaksi. Data dienkripsi dalam transit oleh infrastruktur Firebase.

4. Akses Administrator

Aplikasi memiliki panel admin internal yang memungkinkan administrator resmi melihat daftar pengguna dan data transaksi seluruh pengguna, semata-mata untuk pemeliharaan, dukungan teknis, dan pemantauan operasional. Administrator tidak dapat mengubah atau menghapus data transaksi milik pengguna lain.

5. Berbagi Data ke Pihak Ketiga

Kami tidak menjual atau membagikan data pribadi ke pihak ketiga untuk tujuan pemasaran. Data hanya diproses oleh penyedia infrastruktur (Firebase/Google Cloud) sebagai bagian dari operasional Aplikasi.

6. Hak Pengguna

  • Mengakses data pribadimu kapan saja melalui Aplikasi
  • Meminta penghapusan akun beserta seluruh data transaksi terkait, dengan menghubungi kontak di bawah
  • Memperbarui informasi profil melalui Aplikasi

7. Privasi Anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan data dari anak di bawah usia tersebut.

8. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan signifikan akan diinformasikan melalui Aplikasi.
